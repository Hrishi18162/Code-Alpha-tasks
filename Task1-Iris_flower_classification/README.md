#  Iris Flower Classification

##  Project Description

This project focuses on classifying Iris flowers into three different species—Setosa, Versicolor, and Virginica—using Machine Learning techniques. The classification is performed based on the flower's sepal and petal measurements.

The project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis, model training, evaluation, and prediction using Python and Scikit-learn.

---

##  Objective

To build a machine learning model that can accurately predict the species of an Iris flower based on its physical characteristics.

---

##  Dataset Information

The dataset contains the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species (Target Variable)

---

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

##  Project Workflow

1. Import and load the dataset
2. Explore and visualize the data
3. Prepare the data for training
4. Split data into training and testing sets
5. Train the machine learning model
6. Evaluate model performance
7. Make predictions on new data

---

##  Machine Learning Model

- Random Forest Classifier
- Train-Test Split
- Accuracy Score Evaluation

---
##  Results

The trained model achieved high classification accuracy and successfully identified Iris flower species based on the given measurements.
